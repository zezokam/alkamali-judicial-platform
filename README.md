# المرجع القضائي - المنصة الجديدة

منصة قانونية متكاملة ومتطورة تقدم مجموعة شاملة من الأدوات والمراجع القضائية لمساعدة المختصين والمهتمين في المجال القانوني.

## المؤلف
**القاضي عزان الكمالي**

## الميزات الجديدة

### 🎨 تصميم احترافي متطور
- واجهة مستخدم عصرية وأنيقة
- تصميم متجاوب يعمل على جميع الأجهزة
- ألوان وتنسيق يعكس الاحترافية القانونية

### 📚 مكتبة قانونية شاملة
- **القانون المدني**: قانون المعاملات المدنية، قانون الإثبات، وأكثر
- **القانون الجزائي**: الجزاء العام والخاص، قانون الإجراءات الجزائية
- **القانون التجاري**: قانون التجارة، الشركات التجارية، الإفلاس
- **القانون الشرعي**: قانون الأحوال الشخصية، الديات والأروش

### 🧮 أدوات حسابية متقدمة
- حاسبة مكافأة نهاية الخدمة (القانون الجديد والقديم)
- حاسبة النفقة التقديرية
- أدوات حسابية إضافية للمجال القانوني

### 🗃️ قواعد بيانات قضائية
- المبادئ القضائية
- الأبحاث والتعليقات القانونية
- مسودات الأحكام
- المكتبة القانونية

## التقنيات المستخدمة

- **HTML5** - هيكل الصفحات
- **CSS3** - التصميم والتنسيق المتقدم
- **JavaScript** - التفاعل والوظائف الديناميكية
- **خط Tajawal** - خط عربي احترافي من Google Fonts

## البنية

```
├── index.html              # الصفحة الرئيسية
├── css/                    # ملفات التنسيق
│   ├── main.css           # التنسيق الرئيسي
│   ├── components.css     # تنسيق المكونات
│   └── responsive.css     # التصميم المتجاوب
├── js/                     # ملفات JavaScript
│   ├── main.js            # الوظائف الرئيسية
│   └── calculators.js     # وظائف الحاسبات
├── pages/                  # الصفحات الفرعية
│   ├── legal-sections/    # الأقسام القانونية
│   ├── calculators/       # صفحات الحاسبات
│   └── databases/         # قواعد البيانات
├── assets/                 # الموارد
│   ├── images/            # الصور
│   └── icons/             # الأيقونات
└── docs/                   # الوثائق
```
